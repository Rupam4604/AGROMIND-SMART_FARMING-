# Smart Farming V2.0

An ESP32-based IoT smart farming system with Firebase cloud integration.

## Features

-   ESP32 DevKit V1
-   DHT22
-   Soil moisture monitoring
-   Water level monitoring
-   Automatic Pump, Fan, Humidifier and Grow Light
-   20x4 LCD
-   Firebase Realtime Database
-   Auto/Manual modes
-   Scheduler-based firmware

## Hardware

-   ESP32 DevKit V1
-   DHT22
-   2 Soil Moisture Sensors
-   LDR
-   2 Water Level Sensors
-   4-Channel Relay
-   LCD 20x4 I2C
-   Pump, Fan, Humidifier, Grow Light
